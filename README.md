# sutto-download
# すっと ― ずぼらの人のためのファイル管理ツール

散らかったファイルを、「入れる場所を選ぶだけ」で整理する Windows 用のアプリです。

- ファイルやフォルダをドロップして、行き先を選ぶだけ（ものごとに別々の行き先にして、まとめて入れることもできます）
- **上書きしません**。同じ名前があれば「(1)」を付けて両方残します
- **消しません**。消すときは、Windows のごみ箱へ移します
- 実行する前に、必ず確認の画面が出ます。30日以内なら、あとから元の場所へ戻せます
- インターネットには接続しません。集めている情報もありません

動作環境：Windows 10 / 11

## ダウンロード

右側の **Releases → 最新版（Latest）** を開いて、次のどちらかをダウンロードしてください。

| ファイル | 使い方 |
|---|---|
| `Sutto-Setup.exe` | インストーラー。ダブルクリックして、案内どおりに進めます（非推奨） |
| `Sutto-win64.zip` | インストール不要。展開（すべて展開）して、中の `FileMgrLocal.exe` を開きます（推奨） |

## 初めて開くときの警告について

署名（有料の証明書）をまだ付けていないため、初めて開くときに Windows が「PCが保護されました」と表示することがあります。

**「詳細情報」→「実行」** で開けます。

心配なときは、ダウンロードしたファイルが、配布されたものと同じか確かめられます（PowerShell）。

```powershell
Get-FileHash ダウンロードしたファイルのパス -Algorithm SHA256
```

出てきた値が、Releases にある `SHA256.txt` の値と同じなら、改ざんされていません。

## 困ったとき

動作の記録は `%APPDATA%\FileMgrLocal\debug.log` にあります。
